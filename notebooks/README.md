# Notebooks Directory

This directory contains exploratory Jupyter notebooks for algorithm experimentation, map visualization, and metric analysis.

## Planned Notebooks
- `01_grid_map_exploration.ipynb`: Grid map generation, obstacle rendering, and resolution benchmarks.
- `02_path_planning_comparison.ipynb`: Visual and performance comparison between A*, Dijkstra, and planned search methods.
- `03_evaluation_metrics.ipynb`: Analyzing path optimality, safety margins, and execution time.
